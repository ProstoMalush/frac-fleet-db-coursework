# Этап 5. Бизнес-запросы

Все запросы рассчитаны на PostgreSQL 15 и созданную схему `frac_core`.
Они только читают данные и не изменяют таблицы.

## Порядок

1. `02_repairs_by_field_quarter.sql` — ремонты по месторождениям и кварталам.
2. `03_fleet_performance.sql` — рейтинг флотов по суммарной фактической продолжительности; используется `DENSE_RANK()`.
3. `04_repeat_repairs_by_well.sql` — повторные ремонты скважин; используется `LAG()`.
4. `05_telemetry_above_stage_average.sql` — измерения выше среднего давления своего этапа более чем на 3%; используется коррелированный подзапрос.
5. `06_equipment_maintenance_by_fleet_cte.sql` — состояние оборудования по флотам; используются CTE (`WITH`) и последняя запись ТО.
6. `07_telemetry_above_stage_average_noncorrelated.sql` — некоррелированный вариант запроса № 4 для сравнения и объяснения преобразования коррелированного подзапроса в JOIN + CTE.

## Соответствие бизнес-вопросам

| Бизнес-вопрос | Файл |
|---|---|
| Ремонты по месторождениям за квартал | `02_repairs_by_field_quarter.sql` |
| Производительность флотов | `03_fleet_performance.sql` |
| Повторные ремонты скважин | `04_repeat_repairs_by_well.sql` |
| Технические параметры ремонтов | `05_telemetry_above_stage_average.sql` |
| Оборудование и техническое обслуживание | `06_equipment_maintenance_by_fleet_cte.sql` |

## Важные замечания

- Данные в проекте синтетические и не являются производственными данными Газпром нефти.
- В коррелированном запросе подзапрос обращается к `m.repair_stage_id` внешнего запроса; поэтому среднее давление вычисляется отдельно для этапа текущего измерения.
- Файл `07_telemetry_above_stage_average_noncorrelated.sql` решает ту же задачу без корреляции: сначала агрегирует телеметрию в CTE, затем соединяет средние значения с измерениями по `repair_stage_id`.
- `LAG()` возвращает окончание предыдущего ремонта той же скважины в хронологическом порядке.
- В запросе с CTE дата просрочки определяется относительно `CURRENT_DATE`, то есть может меняться при запуске в разные дни.
- Для воспроизводимости скриншотов фиксируйте дату запуска в пояснительной записке.
- Не называйте учебный порог `3%` технологическим нормативом: это аналитический фильтр-пример.
