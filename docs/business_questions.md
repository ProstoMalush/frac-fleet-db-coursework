# Бизнес-вопросы базы данных флотов ГРП

База данных должна предоставлять информацию для решения следующих пяти бизнес-вопросов.

## 1. Какие ремонты выполнялись на каждом месторождении за выбранный квартал?

**Что требуется получить:** количество ремонтов по каждому месторождению, перечень видов работ, число затронутых скважин и распределение операций по статусам.

**Основные данные:** `oil_field`, `well`, `well_repair`, `repair_type`.

**Польза для анализа:** сравнение производственной активности месторождений и структуры выполняемых работ за период.

## 2. Какие флоты ГРП выполняли больше всего ремонтов и какова их средняя продолжительность?

**Что требуется получить:** рейтинг флотов по количеству выполненных операций, суммарная и средняя продолжительность ремонтов, количество незавершённых работ.

**Основные данные:** `frac_fleet`, `well_repair`.

**Польза для анализа:** оценка загрузки флотов и сравнение их производительности.

## 3. На каких скважинах ремонты проводились повторно и сколько времени прошло между соседними ремонтами?

**Что требуется получить:** список скважин с повторными ремонтами, даты предыдущего и текущего ремонтов, интервал между ними в днях.

**Основные данные:** `well`, `well_repair`.

**Польза для анализа:** выявление скважин с высокой частотой ремонтных воздействий и подготовка объектов для дополнительного анализа.

## 4. Какие технологические параметры фиксировались на этапах ремонта и как они изменялись?

**Что требуется получить:** среднее и максимальное давление, средний расход жидкости, концентрацию проппанта и объём жидкости по этапам, ремонтам и флотам.

**Основные данные:** `well_repair`, `repair_stage`, `telemetry_measurement`, `frac_fleet`.

**Польза для анализа:** сравнение технологических параметров между этапами и операциями, поиск отклонений и подготовка аналитических отчётов.

## 5. Какое оборудование закреплено за каждым флотом и какие единицы оборудования требуют обслуживания?

**Что требуется получить:** действующий состав каждого флота на выбранную дату, типы и количество оборудования, список единиц с незавершённым или запланированным обслуживанием.

**Основные данные:** `frac_fleet`, `equipment_unit`, `equipment_type`, `fleet_unit_assignment`, `equipment_maintenance`.

**Польза для анализа:** контроль комплектности флотов и выявление оборудования, которое может ограничивать готовность флота к выполнению работ.

---

## Связь бизнес-вопросов с требованиями к SQL

| Бизнес-вопрос | Основные SQL-конструкции для демонстрации |
|---|---|
| 1. Ремонты по месторождениям и кварталам | `JOIN`, фильтрация по датам, `GROUP BY`, агрегатные функции |
| 2. Рейтинг флотов | CTE, агрегатные функции, сортировка и ранжирование |
| 3. Повторные ремонты | Оконная функция `LAG()` |
| 4. Технологические параметры | `JOIN`, CTE, `AVG()`, `MAX()`, `SUM()` |
| 5. Состав флотов и обслуживание | Коррелированный подзапрос `EXISTS` или `NOT EXISTS`, проверка временных интервалов |

Пять итоговых запросов будут подготовлены на основе этих вопросов. Для выполнения требования преподавателя среди них обязательно будут представлены коррелированный подзапрос, CTE и оконная функция.
